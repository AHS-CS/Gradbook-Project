# GradeBook partner project — package contents

`STUDENT_REPO/` contains all materials to place in the shared student GitHub repository: project README, milestone instructions, GitHub workflow, interface reference, issue/PR templates, test checklist, sample data, and a placeholder for teacher-supplied Java starter files.

`TEACHER_PRIVATE/` contains private grading/review guidance, an Issue plan, and setup instructions. **Never copy this directory into a student repository.**

The package is based on six supplied GradeBook 0–5 handouts. It intentionally does not invent missing Java starter files, constructor signatures, due dates, or grading rules for unspecified edge cases.

## Starter code update
This revision includes all 10 supplied original Java starter files in `STUDENT_REPO/src/` and the original `gradebook.dat` at the repository root. The file runner uses `new File("gradebook.dat")`, so run from the repository root. The starter project is intentionally incomplete and does not initially compile.
