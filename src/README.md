# Java starter files go here

Before distributing this repository, the teacher should copy the actual starter `.java` files from the course materials into this directory. The six uploaded lab handouts contain **partial class skeletons**, but do not supply all runner implementations or all constructors. This package intentionally does not invent full Java starter files.

Expected final files: `Grade.java`, `Grades.java`, `Student.java`, `Class.java`, `GradeBookRunner.java`, `GradeBookFileRunner.java`. Original lab-specific runners may be retained for testing if provided by the teacher.

Use the default package unless the teacher's starter project uses a different package structure. Compile with the course's normal Java workflow.
